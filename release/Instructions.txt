Installation Instructions

Several binary, HEX Files are provided in the /release folder. To get started, we suggest to flash:

mdt_PROGMEM-CAPACITIVE_TOUCH_(latest version number you see).hex


Upload HEX file to your Teensy 4.1:

You just need the Teensy Loader application and your HEX file. 

Get Teensy Loader
https://www.pjrc.com/teensy/loader.html

- [x] connect your teensy to your computer with a known working USB-Micro-B to USB-A data cable.

- [x] launch teensy loader

- [x] Drop the HEX file onto Teensy Loader

- [x] Push the button on the Teensy and Teensy Loader should send the program to the Teensy.

* Copy all Files/Directories from /addon/SD/ to the root of your SD Card (FAT32) and insert the card in SD Slot of the Teensy 4.1

* Power on the Teensy and attach USB MIDI Keyboard (or use the virtual Touch Keyboard and the Encoders to navigate)


In the subfolder "32MB_PSRAM (ONLY-TESTING-UNSTABLE)" are firmware versions that support the new 16MB PSRAM chip(s) - It should work with one or two chips of these, however it is named "32MB" since it does not make sense to have only one chip - since that same memory you could also get with the previously 2x8 MB, well tested, configuration. These versions are currently only for testing purposes, they are not fully stable.


Firmware in the LEGACY_PROGMEM_ONLY Folder are only for a quick test with a Teensy without any PSRAM. It is lacking a lot of features and functionality like only having 2 dexed instances instead for 4 and only very limited free memory for the LiveSequencer.

Firmware in the MAM_MUSIKANDMORE folder are only for special hardware builds by musikandmore
